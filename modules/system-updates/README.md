# system.updates

On-demand read-only проверка обновлений Ubuntu. Worker запускает только
симуляцию APT с отключёнными lock-файлами: он не обновляет package lists, не
устанавливает пакеты и не требует root.

Результат сообщает число доступных и security-обновлений, ограниченный preview
имён пакетов и свежесть локального APT-кэша. Если кэш устарел, интерфейс должен
открыть штатный `update-manager`, который выполнит авторитетную проверку через
стандартный Ubuntu/PolicyKit workflow.
