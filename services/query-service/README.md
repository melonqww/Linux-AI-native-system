# Query Service

Единая read-only точка поиска поверх метаданных Storage Catalog и содержимого
SQLite FTS. PDF сначала безопасно извлекается модулем `documents.pdf`, затем
индексируется без повторного чтения исходного файла текстовым индексатором.

Расширение, том и имя являются фильтрами. Если задан текст содержимого, сервис
не добавляет нерелевантные документы только потому, что у них совпало
расширение.

`DocumentQuery.mode` задаёт смысл явно: `metadata` ищет по имени, расширению или
диску без content query; `content` использует полнотекстовый индекс; `hybrid`
совмещает содержимое с metadata-фильтрами. Новые планы передают mode явно, а
старые внутренние планы нормализуются детерминированно без таблицы фраз.

`QueryRuntimeApplication` валидирует JSON панели и преобразует его в
`DocumentQuery`. Из результатов можно сохранить immutable snapshot-коллекцию,
которая затем передаётся в Materialize Service.

Каталогизация диска и извлечение PDF не выполняются внутри интерактивного
поискового запроса: это сохраняет низкую задержку интерфейса. Их должен запускать
фоновый scheduler после подключения диска или изменения файлов.
