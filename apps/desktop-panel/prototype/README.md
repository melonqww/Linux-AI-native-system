# Desktop panel prototype

Это интерактивный HTML/CSS/JS-макет правой панели AI-native Linux. Он не требует сборки или зависимостей: откройте `index.html` в браузере.

В макете работают отправка демонстрационного сообщения, отображение фоновой
генерации, переключение на настройки и концепт `software.manager`: круглая кнопка
библиотеки, каталог из 20 приложений, поиск, установка с прогрессом, библиотека,
запуск/закрытие, подтверждение удаления и восстановление бэкапа через отдельное
состояние установки в каталоге. Карточки содержат ссылки на официальные сайты.
Во время установки макет показывает скорость и примерное оставшееся время без
повторной анимации карточек, подтверждённую паузу, продолжение, отмену и состояние
ожидания сети. Для просмотра offline-состояния можно открыть `index.html?offline`.
Уведомление о завершении намеренно не рисуется внутри панели: рабочая Linux-версия
отправляет его в системный центр уведомлений. Это только
визуальный прототип; системные операции он не выполняет.

Реальная desktop-реализация для Ubuntu будет подключать тот же UX к Python runtime и локальному Ollama API.
