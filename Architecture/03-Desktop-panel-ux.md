# UX правой AI-панели — v0.1

## Назначение

Панель — основной интерфейс системного AI-помощника. Она закреплена у правого края экрана и не заменяет рабочий стол, верхнюю панель GNOME или стандартные уведомления.

При первом входе в Ubuntu панель открывается автоматически. Позже она вызывается горячей клавишей, значком в верхней панели и кликом по уведомлению AI.

## Компоновка

```text
┌────────────────────────────────────────────┐
│ [☰]  Новый чат                    [⚙]      │
│      ~/Projects/Linux AI System             │
├────────────────────────────────────────────┤
│                                            │
│  AI отвечает обычным белым текстом.         │
│                                            │
│                  [Сообщение пользователя]  │
│                                            │
│  Карточка плана или результата действия.    │
│                                            │
├────────────────────────────────────────────┤
│ [＋]  Напишите сообщение…              [↑] │
└────────────────────────────────────────────┘
```

- Панель имеет тёмно-серый фон, светлый текст и минимум декоративных элементов.
- Сообщения пользователя — белые овальные карточки с тёмным текстом, выровненные вправо.
- Ответы AI — белый текст без отдельного пузыря, выровненный влево.
- Поле ввода всегда закреплено снизу. В нём есть прикрепление файла и отправка.
- Путь под названием чата отражает текущую рабочую директорию задачи. Это контекст, а не неограниченное разрешение читать её содержимое.

## Верхняя панель

| Элемент | Поведение v0.1 |
|---|---|
| `☰` | Открывает список чатов; до появления истории показывает краткий список-заглушку. |
| Название | По умолчанию «Новый чат», позднее становится кратким названием задачи. |
| Директория | Динамически показывает текущую директорию workspace. |
| `⚙` | Полностью заменяет область чата экраном настроек. |

## Настройки и фоновая генерация

Экран настроек не открывается поверх чата: он заменяет содержимое панели. При этом запрос к модели не отменяется. Верхняя строка показывает статус «AI отвечает»; когда пользователь возвращается в чат, готовый ответ появляется в переписке.

Первые разделы настроек: `OS & интеграции`, `Безопасность`, `Модели`, `Приватность`, `О приложении`.

## Уведомления

Короткое системное уведомление GNOME сообщает о завершении важной задачи. Клик по нему открывает эту панель на соответствующем чате. Подтверждение рискованных изменений выполняется только в самой панели.
