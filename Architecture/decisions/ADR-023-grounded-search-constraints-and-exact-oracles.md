# ADR-023: Сохранение search-ограничений и точные файловые oracle

**Статус:** принято 2026-09-05

## Контекст

Безопасно исполненный план может решать не ту задачу. В сохранённом успешном
journey пользователь уточнил «нужны только PDF по математике», но модель оставила
только расширение PDF и добавила не запрошенный язык. Оркестратор честно
скопировал три файла, а лаборатория приняла результат, потому что проверяла лишь
диапазон количества. Один из фильтров `languages` при этом вообще не применялся
Query Service и возвращал только warning.

Такой результат нельзя считать успешным основным сценарием: policy и approval
защищают полномочия, но не доказывают правильность выбранных объектов.

## Решение

Предметная часть запроса является обязательным search-ограничением. Model
adapter явно различает type-only metadata search и subject/content search:
сочетание предмета с расширением требует `hybrid`, а исправление пользователя
строится из всех ограничений текущего сообщения. Это правило описывает форму
задачи, а не перечень тематик; в production-коде нет словаря «математика» или
других предметов.

Публичный capability-контракт содержит только исполняемые фильтры. До появления
надёжного определения языка `languages` удалён из Manifest v2, model schema,
validator и trusted Permission Gateway policy. Старый план с этим аргументом
закрыто отклоняется; система не выполняет более широкий поиск под видом
отфильтрованного.

AI Scenario Lab получает два детерминированных oracle:

- scenario может сравнить точные `result_paths` и `copied_paths` в виртуальном
  namespace;
- adaptive journey задаёт точный обязательный файловый эффект и отдельный общий
  максимум эффектов этого типа.

Journey поиска математических PDF теперь проходит только при копировании одного
измеренного файла `algebra.pdf`. `broken.pdf`, файл неверного типа или любой иной
лишний результат делают проверку красной независимо от текста модели.

## Последствия и ограничения

- Совпадение количества больше не маскирует неправильный выбор объектов.
- Неисполняемый фильтр не может молча ослабить запрос.
- Permission Gateway остаётся независимой границей полномочий.
- Улучшенная инструкция снижает вероятность потери предмета маленькой моделью,
  но не является математическим доказательством понимания любого языка.
- Межъязыковой semantic retrieval и проверка полноты составного графа реализованы
  позднее в ADR-026; они не подменяются hardcoded словарями в этом ADR.

ADR-023 дополняет ADR-019 и ADR-022: candidate routing выбирает допустимую
операцию, capability contract описывает её исполняемые аргументы, а точный lab
oracle проверяет фактический смысл результата.
