# ADR-038: подтверждение карантина в Security Center

**Статус:** принято и реализовано в `security.center` `0.9.0`.

## Решение

Панель не вызывает перемещение напрямую по `finding_id`. Сначала worker повторно
проверяет находку и создаёт одноразовый server-owned receipt. UI показывает путь,
размер и обратимость операции. Только второе явное действие пользователя вызывает
commit через Permission Gateway. Отмена инвалидирует receipt.

Восстановление является отдельной подтверждаемой R1-операцией. Оно никогда не
перезаписывает существующий объект и повторно проверяет digest до и после move.

## Последствия

- один клик по finding не изменяет файловую систему;
- подмена файла после preview приводит к fail-closed результату;
- неподтверждённые receipts нельзя продолжить после перезапуска worker;
- панель показывает только bounded metadata и не получает путь quarantine object;
- безвозвратное удаление по-прежнему отсутствует.
