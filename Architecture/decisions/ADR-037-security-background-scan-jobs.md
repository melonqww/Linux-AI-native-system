# ADR-037: фоновые scan jobs Security Center

**Статус:** принято и реализовано в `security.center` `0.8.0`.

## Решение

Долгие проверки выполняются внутри изолированного worker в отдельном потоке.
Первичный IPC-запрос только создаёт job; панель затем опрашивает короткий status
endpoint и может запросить отмену. CampaignScanner сообщает реальные значения
после каждого файла, поэтому UI не симулирует процент таймером.

В один момент разрешена одна job. Завершённые результаты и настройка автоматики
сохраняются без путей и содержимого. Автоматический quick scan является opt-in,
работает раз в 24 часа и не отключает ручные проверки.

## Последствия

- закрытие или переключение панели не прерывает scan;
- панель показывает файлы, байты, угрозы и прошедшее время;
- cancel является cooperative и срабатывает между bounded file operations;
- full scan не запускается параллельно с другим scan;
- автоматический режим можно включить и выключить без изменения прав модуля.
