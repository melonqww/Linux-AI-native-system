# ADR-004: Модельно-независимый Intent Compiler

**Статус:** принято  
**Дата:** 2026-08-19

## Контекст

Система должна понимать свободные русские и английские запросы, продолжения
вроде «скопируй их туда» и составные цели. Набор заранее прописанных фраз быстро
становится хрупким и не является пониманием языка. Одновременно нельзя позволять
модели придумывать shell-команды, пути, capability или выполненные результаты.

## Решение

Вводится отдельный `intent-compiler` с двумя принципиально разными частями:

1. Подключаемый model provider переводит язык в небольшое семантическое AST.
2. Детерминированное ядро валидирует AST, разрешает доверенный контекст и строит
   план из capability, объявленных системой.

Операции и типы аргументов фиксируются как системный контракт; конкретные
формулировки пользователя не фиксируются. Model output считается недоверенным:
неизвестные поля, неподдерживаемые операции, произвольные ссылки, URL с учётными
данными и не подтверждённые исходным текстом evidence отклоняются.

Модель получает только текст запроса, locale, закрытую JSON Schema и признаки
наличия контекста. Реальные пути и ID коллекций остаются у runtime. Для
продолжений модель использует `context.active_results` и
`context.last_destination`; ядро заменяет их значениями из состояния задачи.

Планирование ничего не выполняет. Каждый шаг содержит capability, зависимости,
класс риска и признак approval. Недоступная capability даёт `unavailable`, низкая
уверенность или отсутствующий контекст — `needs_clarification`. Изменяющее
копирование классифицируется как R1 и перед исполнением проходит отдельный
Permission Gateway и одноразовое подтверждение.

## Последствия

- можно менять локальную/облачную модель без изменения planner и policy;
- добавление модуля расширяет capability, но не полномочия модели;
- языковое качество проверяется отдельными eval-наборами, а safety-инварианты —
  обычными детерминированными тестами;
- production adapter и исполнение планов остаются отдельными следующими слоями;
- исходное содержимое PDF/web не смешивается с инструкциями компилятору, что
  уменьшает поверхность prompt injection.

## PDF и OCR

Intent Compiler описывает цель поиска и не разбирает PDF сам. `documents-pdf`
до чтения применяет лимиты размера и страниц, безопасно отклоняет битые и
зашифрованные файлы, а документы без текстового слоя направляет в будущий OCR
модуль. OCR для русского, английского, формул, таблиц и графиков будет отдельной
capability с собственными бюджетами CPU/RAM, таймаутами и показателями качества.
