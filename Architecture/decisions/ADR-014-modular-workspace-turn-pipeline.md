# ADR-014: Модульный Workspace Turn Pipeline v2

**Статус:** принято 2026-08-22

## Контекст

Один запрос может одновременно содержать обычный вопрос и системное действие.
Tool call локальной модели не гарантирует текстовый ответ, а нулевой результат
поиска нельзя считать доказательством отсутствия файлов без полного индекса.

## Решение

Гибридный turn остаётся координацией модулей, а не новым монолитом:

- `intent-compiler` предлагает действие и явный режим поиска;
- `query-service` исполняет только `metadata`, `content` или `hybrid` query;
- `index-scheduler` публикует полноту покрытия разрешённых дисков;
- `execution-orchestrator` возвращает типизированный `SearchOutput`;
- `workspace-service` связывает естественный ответ и проверенный task result;
- Permission Gateway остаётся единственным владельцем решения об исполнении.

После действия Qwen формирует только независимую разговорную часть. Количество,
пути, полнота индекса и итог операции создаются backend. Источник публичного
сообщения равен `qwen`, `system`, `tool` или `user`.

Контекст Qwen ограничен 8192 токенами. Workspace передаёт не более 12 последних
сообщений и 8000 символов истории; task result содержит компактную проверенную
проекцию фактов вместо внутренних объектов исполнения.

## Последствия

Новые действия расширяют semantic tools и capability-модули, но не раздувают
Workspace и не дают модели прямого доступа к исполнителю. Старые планы поиска
без `mode` нормализуются детерминированно; новые model calls задают mode явно.
