# Подготовка Ubuntu VM для разработки

## Создание машины в VirtualBox

1. В `File → Preferences → General` укажите папку машин: `D:\VirtualMachines`.
2. Нажмите «Создать» и назовите машину `ai-native-linux-dev`.
3. Выберите ISO `ubuntu-24.04.4-desktop-amd64.iso`.
4. Выделите 8 ГБ RAM, 4 CPU и динамический диск VDI на 60 ГБ.
5. Оставьте сеть в режиме NAT и включите 3D acceleration.
6. Запустите машину и в установщике выберите обычную установку Ubuntu Desktop.

## После установки

1. Выполните обновления системы.
2. В VirtualBox выберите `Devices → Insert Guest Additions CD Image`, затем установите дополнения гостевой ОС и перезапустите Ubuntu.
3. Создайте snapshot с названием `clean-ubuntu-base`.
4. Не включайте общие папки Windows и Ubuntu, пока не определим ограниченную модель обмена файлами для разработки.

Snapshot нужен, чтобы быстро вернуться к чистому состоянию после любого неудачного эксперимента с системными сервисами.
